# Subnetting Master · Network Engineering Suite

A premium, cyber-luxury network engineering tool designed for students, network engineers, and IT professionals.  
Perform advanced subnetting calculations (VLSM, FLSM, IPv6) with an immersive, high-performance interface.

**100% Client-Side.** No backend. No data tracking. All calculations run instantly in your browser.

---

### ✨ Why use this?
- Simplify complex network calculations for exams or real-world network design.
- Replace multiple manual calculators with a single, elegant, and professional suite.
- Learn subnetting faster with built-in cheat sheets and live visual feedback.

---

### 🔧 Key Features
- **🧩 VLSM Calculator:** Perform Variable Length Subnet Mask calculations with custom host requirements.
- **📊 IPv4 FLSM Subnetting:** Calculate Fixed Length Subnet Mask subnets and broadcast addresses quickly.
- **🌍 IPv6 Subnet Generator:** Generate IPv6 subnets with ease.
- **📚 CIDR Cheat Sheet:** A quick reference for CIDR notation, subnet masks, and usable hosts.
- **🛠️ Mini Tools:**
  - CIDR ↔ Subnet Mask Converter
  - Wildcard Mask Calculator
- **📁 Local History:** Your recent calculations are saved locally in your browser for quick access.
- **🎨 Cyber-Luxury UI:** Neon Amethyst aesthetic with floating particle backgrounds and smooth animations.
- **📱 Fully Responsive:** Works flawlessly on desktops, tablets, and mobile devices.

---

### 🚀 Quick Start
1. Select your desired tool from the navigation bar (**VLSM, IPv4, IPv6, Cheatsheet**).
2. Enter your network details (e.g., `192.168.1.0/24`).
3. Click the **"Calculate"** or **"Generate"** button.
4. View the detailed results in the table and copy any value with a single click.
